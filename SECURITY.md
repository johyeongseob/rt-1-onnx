# Security Policy

We aim to address security issues responsibly and provide clear guidance when
a vulnerability affects this project.

## Reporting a Vulnerability

Please report security vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/johyeongseob/rt-1-onnx/security/advisories/new).
Do not disclose sensitive details in a public issue.

This is a research project, not a safety-certified robot controller.
TensorFlow-ONNX output equivalence does not establish physical robot safety.
